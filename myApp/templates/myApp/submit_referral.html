Refer a Landlord & Earn Ksh. 100

Submit the M-Pesa code of the landlord's payment to claim your reward.

Referral Instructions

To qualify for the reward, ensure you collect and submit the following:

  • Landlord’s Full Name – as used when registering on the platform.
  • Landlord’s Phone Number – the one used to make the M-Pesa payment.
  • M-Pesa Transaction Code – from a successful payment.

Disqualification Conditions

  • If the name does not match the registered landlord.
  • If the phone number is different from the one used to pay.
  • If the M-Pesa code is invalid or has already been used.
  • If the landlord has already been referred (only one referral per landlord).
